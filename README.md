# Challenge-Data-Science-Alura-Store
Primer Challenge certificación en Data Science Alura ONE


Análisis de Ventas en Múltiples Tiendas

Este proyecto se centra en examinar de manera detallada los datos de ventas de 4 tiendas, con la posibilidad de ampliarse a más establecimientos. Su finalidad es detectar los ingresos netos, determinar los productos más y menos rentables, destacar categorías relevantes y reconocer patrones que respalden la toma de decisiones basadas en datos.

Objetivo del Análisis

El análisis busca:

Calcular los ingresos netos de cada tienda.

Medir la rentabilidad de productos específicos.

Comparar el rendimiento entre distintas categorías.

Identificar los artículos que generan mayores costos de mantenimiento.

Representar los resultados con gráficos para facilitar la comprensión.

Pasos para Ejecutar el Notebook

Clonar el repositorio.

Instalar las bibliotecas necesarias: pip install pandas matplotlib numpy.

Abrir y ejecutar el notebook en Google Colab.

Cargar los archivos .csv, asegurándose de que incluyan las columnas ‘Producto’, ‘Categoría’, ‘Precio’, ‘Costo de envío’, ya que son la base del análisis.

Funcionalidades Principales

Cálculo del ingreso neto por tienda.

Agrupación de ventas según categorías.

Ranking de productos con mayor y menor rentabilidad.

Detección de productos con altos costos operativos.

Generación de gráficos para mejorar la interpretación de la información.
